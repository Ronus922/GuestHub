# סגירת חדר זמנית — חלון צד (Room Block Drawer)

מסך ייחוס: `סגירת חדר זמנית.dc.html`
מחליף את חלון "סגירת חדר זמנית" הקיים (שני שדות `<input type="date">` + באנר שגיאה ורוד + טופס בעמודה אחת).

**רוחב החלון, אנימציית הפתיחה וה-backdrop — לפי הסטנדרט הקיים של חלונות הצד במערכת. אין לשנות אותם בגלל המסך הזה.**

---

## 1. מה מוחלף ולמה

| קיים | חדש |
|---|---|
| שדות נמתחים לכל רוחב החלון | תוכן בשתי עמודות, שדה לא עובר ~560px |
| `מתאריך` / `עד תאריך (לא כולל)` — שני שדות date נייטיביים | **תאריכון דו-חודשי** לבחירת לילות בקליק |
| באנר אדום "הסגירה מכסה 1 לילות · הלילה האחרון הסגור הוא…" | שורת סיכום חיה בפוטר + הודעת מצב אחת בתחתית הגוף |
| דרופדאון "בחירת סיבה…" + טקסט עזר | **צ'יפים** של 6 סיבות קבועות |
| "בחירת חדר…" ריק | בוחר חדר עם מספר, סוג, מחיר ומצב הזמנות |
| שטח ריק עצום מתחת לטופס | אין — הפוטר תמיד צמוד לתחתית |

**אין להשתמש ב-`<input type="date">` בחלון הזה.** אייקון הלוח הנייטיבי מופיע בצד ההפוך ב-RTL, אין הצגת התנגשויות, והמושג "עד תאריך לא כולל" לא מובן למשתמש.

## 2. מבנה החלון

```
Drawer (רוחב ומיקום לפי הסטנדרט הקיים של חלונות צד)
├── Header  — פס כחול #2540C8, גובה ~70px
│   ├── אייקון בריבוע rgba(255,255,255,.16) · event_busy
│   ├── כותרת 21px/800 לבן  "סגירת חדר זמנית"
│   ├── תת-כותרת 14px rgba(255,255,255,.75) "החדר לא יוצע להזמנה בתאריכים שתבחר"
│   └── כפתור סגירה 34px, רקע rgba(255,255,255,.16)  (hover .3)
├── Body  (רקע #F1F3F8, padding 18px, gap 14px, גלילה פנימית)
│   ├── שורת flex-wrap:
│   │   ├── עמודה ימנית  flex:1 1 330px   → כרטיס "חדר" + כרטיס "סיבת הסגירה"
│   │   └── עמודה שמאלית flex:1 1 620px   → כרטיס "לילות סגורים" (תאריכון)
│   └── הודעת מצב (ירוקה/אדומה) ברוחב מלא
└── Footer — לבן, border-top 1px #E7EAF1
    ├── ימין: סיכום חי — 15px/800 + 13.5px/700 muted
    └── שמאל: [סגור חדר] בקצה השמאלי, [ביטול] מימינו
```

הפריסה **חייבת** להיות `flex-wrap` (לא grid עם מיקום מפורש), כדי שהמסך יעבוד בכל רוחב חלון: כשאין מקום לשתי עמודות, התאריכון יורד לשורה נפרדת ואין גלילה אופקית. אין להסתמך על רוחב חלון ספציפי ואין media queries על רוחב המסך.

## 3. התאריכון — שני חודשים

- שני חודשים זה לצד זה, מפריד אנכי `1px #E7EAF1` ביניהם.
- כותרת חודש מעל כל גריד: 15px/800, ממורכזת.
- חיצים **בשורת הכותרת של הכרטיס** (לא בין החודשים): `chevron_right` = חודש אחורה, `chevron_left` = קדימה. שני החיצים מזיזים את שני החודשים יחד.
- ראשי עמודות: `א ב ג ד ה ו ש` — 12px/700 `#9AA1B4`.
- גריד: `repeat(7,1fr)`, `gap:4px`, גובה תא **40px**, `radius:11px`. 42 תאים; תאים מחוץ לחודש `opacity:0` (שומרים על הגריד).

### מצבי תא

| מצב | רקע | טקסט | הערה |
|---|---|---|---|
| רגיל | שקוף | `#1B2233` 15px/600 | |
| עבר (לפני היום) | שקוף | | `opacity:.45`, לא ניתן לבחירה |
| היום | שקוף | `#1B2233` | מסגרת `2px solid #2540C8` |
| בטווח הסגירה — קצה | `#2540C8` | `#FFF` 800 | היום הראשון והאחרון |
| בטווח הסגירה — אמצע | `#DFE5FB` | `#1C2E9A` 800 | |
| הזמנה קיימת | `#FDEDEC` | `#B42318` 800 | נקודה 4px `#B42318` מתחת למספר |
| הזמנה קיימת **בתוך** הטווח | `#B42318` | `#FFF` | התנגשות — נראית מיד |

`title` של תא מוזמן = `הזמנה: {שם האורח}` (טולטיפ).

### לוגיקת בחירה

```
click(date):
  if (pending && date >= start)  → end = date, pending = false
  else                           → start = end = date, pending = true
```
כלומר: קליק ראשון פותח טווח של לילה אחד, קליק שני קובע את **הלילה האחרון**. בוחרים לילות — לא תאריך יציאה. תאריך היציאה מוצג בפוטר: `חוזר לזמינות ב-{end+1}`.

### קיצורים
צ'יפים מתחת לגריד: `לילה אחד` · `3 לילות` · `שבוע` · `עד סוף החודש` — כולם מתחילים מהיום. הצ'יפ פעיל רק אם ה-`start` הוא היום וה-`nights` תואם.
מקרא בקצה השמאלי של אותה שורה: `סגור` (ריבוע כחול) · `הזמנה קיימת` (ריבוע `#FDD9D7`) · `היום` (מסגרת כחולה).

## 4. בוחר החדר

- טריגר בגובה **56px**, `radius:13px`, מסגרת `1.5px #E7EAF1` (hover `#C9D0E2`).
- בתוכו: ריבוע 40px `#EEF1FD` עם מספר החדר `15px/800 #2540C8 dir:ltr` → סוג החדר `15px/700` → מטה `13.5px/600 muted`: `₪550 לילה · יש הזמנות עתידיות` → `expand_more`.
- הפאנל: `position:absolute`, `top:62px`, `radius:14px`, `box-shadow:0 12px 34px rgba(16,24,40,.12)`, `max-height:244px` עם גלילה.
- שורה נבחרת: רקע `#EEF1FD`, ריבוע מספר כחול מלא עם טקסט לבן, `check` כחול בשמאל.
- החלפת חדר **מרעננת את ההזמנות בתאריכון ואת בדיקת ההתנגשות** — לא מאפסת את הטווח.

- נבחר: מסגרת `1.5px #2540C8`, רקע `#EEF1FD`, טקסט `#1C2E9A`, אייקון `#2540C8`.

- מפריד `1px #E7EAF1`, ואז `פירוט לצוות (לא חובה)` — textarea `min-height:74px`, `radius:12px`, 15px, מונה `0/240` בקצה השמאלי של התווית. פוקוס: מסגרת `#2540C8` + `box-shadow:0 0 0 4px rgba(37,64,200,.12)`.

## 6. הודעת מצב + פוטר

**אין באנר שגיאה על חישוב הלילות.** החישוב מוצג כמידע בפוטר, לא כשגיאה.

הודעה אחת בתחתית הגוף, `radius:16px`, `padding:14px 16px`:
- **פנוי** — רקע `#EAF7EF`, מסגרת `#BFE3CD`, `check_circle #0F6B3C`, כותרת `הטווח פנוי — אין הזמנות שנפגעות`, מתחת: `החדר יוסר מהזמינות בכל הערוצים המחוברים`.
- **התנגשות** — רקע `#FDEDEC`, מסגרת `#F5C6C2`, `error #B42318`, כותרת `התנגשות עם {N} לילות מוזמנים`, מתחת: רשימת `{תאריך} · {שם אורח}`.

פוטר:
- סיכום ימין: `3 לילות · 22/08–24/08` (15px/800) + `חדר 201 · חוזר לזמינות ב-25/08` (13.5px/700 muted).
- כפתורים שמאל: `סגור חדר` בקצה השמאלי, `ביטול` מימינו (44px, radius 12px, 15px/700).
- בהתנגשות הכפתור הראשי הופך ל-`סגור בכל זאת` ברקע `#B42318` + צל `rgba(180,35,24,.2)` — חוסם רק אם המערכת אוסרת overbooking; אחרת ממשיך לאישור.

## 7. חוזה נתונים

```ts
// טעינה
GET /api/rooms?active=1
  → { id, number, typeName, basePrice }[]
GET /api/rooms/:id/occupancy?from=YYYY-MM-DD&to=YYYY-MM-DD
  → { date: 'YYYY-MM-DD', bookingId, guestName }[]   // לילות תפוסים בטווח שני החודשים המוצגים

// שמירה
POST /api/room-blocks
  { roomId, startDate, endDate, reason: 'maint'|'fault'|'reno'|'deep'|'own'|'other', note?, force?: boolean }
  → 201 { blockId }  |  409 { conflicts: [{date, bookingId, guestName}] }
```

- `endDate` = **הלילה האחרון הסגור** (inclusive). ההמרה ל-checkout (`endDate + 1`) נעשית בשרת/בשכבת האינטגרציה, לא במסך.
- כשמחליפים חודש או חדר — נטען מחדש `occupancy` לטווח המוצג (עם cache פר `roomId+month`).
- אחרי שמירה מוצלחת: סגירת החלון, טוסט `החדר נסגר ל-{N} לילות`, ורענון היומן.

## 8. מצבי קצה

- **טווח שמתחיל בעבר** — לא ניתן לבחירה; אם הגיע מ-URL, נחתך ליום הנוכחי.
- **טווח שנמשך אל החודש הבא** — נצבע בשני הגרידים; אין הגבלה לחודש אחד.
- **לילה בודד** — הסיכום ביחיד: `לילה אחד`.
- **חדר עם הזמנת ערוץ (OTA)** — ההתנגשות מסומנת אדום כרגיל, אך בטקסט ההודעה מתווסף `דורש עדכון בערוץ`.
- **חלון צר / מובייל** — התאריכון מציג חודש אחד בכל פעם (השני נחתך ב-`flex-wrap`), הכרטיסים נערמים, הפוטר נשאר דביק בתחתית.
