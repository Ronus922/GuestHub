## RTL, מספרים, מובייל, שגיאות

- RTL מלא — נבדק אוטומטית ברנדור (`document.dir === 'rtl'`).
- מספרים: `ltr-num` + `tabular-nums` על כל ערך כספי (אסרשן ברנדרר); תצוגת כסף
  מדויקת לאגורה (הוסרו כל ה-Math.round בתצוגה).
- מובייל 390px: `impl-pricing-controls-mobile.png` — ה-segmented עוטף (flex-wrap),
  יעדי מגע ‏44px (min-h-11).
- מצבי שגיאה גלויים: ולידציות תמחור עולות כ-DomainError (toast) בשמירה;
  quote/rooms כשלים — `role="alert"` (מ-#121); כשל שמירת כרטיס — inline
  `role="alert"` ליד השדות (חדש).
- שינוי מצב מחיר אינו מוחק ערך שהוזן — הערכים נשמרים ב-state והמצב רק בוחר
  מי מהם מתמחר (SPEC כלל 6; pin ב-`check:card-save-flow`... נכון יותר: התנהגות
  onMode ב-PricingControls — הבוררים לא מאפסים שדות).
